# 使用说明

## 开屏动画

设置 → 开屏提供开关和重播。每次页面运行期间自动展示一次；启用系统“减少动态效果”时不自动播放。可用跳过按钮或 Esc 退出。加载或播放失败时回到正常界面，不要求关闭应用。

荷塘浅色且非默认材质使用约 14.6 秒的专属结尾；其他场景、深色和默认材质使用约 9.6 秒的剪影过渡。它会显露当前选择的背景，不会为每个壁纸生成独立人物动作。开屏期间改变选择时安全结束，保留最新偏好。

两段开屏均为 1920×1080、30fps、无声；署名与来源链接独立于视频裁切显示。使用边界见[开屏说明](../packages/skin/docs/OPENING.md)。

## 场景与动态

| 场景 | 动态 |
|---|---|
| 雨声里的片刻 | 循环动态 |
| 窗榻听雨 | 循环动态 |
| 铺卷小憩 | 循环动态 |
| 墨境桥行 | 静态 |
| 掌柜闲时 | 静态 |
| 祀的鬼画符 | 静态 |
| 雪庭温泉 | 开场动作后进入微动态循环 |

温泉开场约 5 秒，之后保持翘腿姿态，循环播放水波、白气与慢雪。专注模式暂停在当前阶段，恢复默认或观赏后继续播放。切换画质保留播放阶段；要重播开场，在设置中先选静态，再选动态。

标准和极清提供两档视频，分辨率随场景比例而异；极清由本地增强得到，并非原生 4K 生成。温泉只有雪日场景，深浅外观共用这组素材。

## 阅读与观赏

设置 → 阅读可调节雾层浓度。默认和专注分别保存设置，重启后保留。观赏隐藏阅读衬底与页面内容，工具栏静止后淡出；鼠标移动或 Tab 可唤回。键盘焦点停留在工具栏时保持可见。

使用 DSH 原生宽度调节时，阅读层跟随实际正文列，窗口缩放和侧栏变化时也会重新对齐；浓度设置不受影响。

观赏期间页面通知和弹层也会隐藏，需处理交互时请先退出观赏。

## 固定会话入口

左栏显示名为 **祀 · 画境**，它打开你已有的会话：

1. 优先匹配唯一且未归档的 **祀 · 管理员的画境会话**。
2. 没有匹配时，查找唯一的 **祀 · 画境** 工作区；其中只有一个未归档、非空的可用会话时，打开该会话。
3. 重名、有歧义或没有有效目标时，入口停用。

可将自己的目标会话重命名为上述完整标题。入口不会自动创建会话、移动记录或发送消息。

## 安装改动范围

安装器向目标 profile 的 package.json 注册本插件依赖和 bundle，通过 cordis.patch.yml 启用皮肤，在数据目录中保存版本、备份与本插件链接；不修改 DSH 可执行文件或 app.asar。首次安装会给检测到的其他 ui-skin-* 条目追加停用配置；已有受控升级保留原 patch。请先退出 DSH，并确认愿意切换皮肤。

可在解压目录执行 `node tools/manage.mjs install` 查看只读安装计划，再决定是否执行 Install.cmd；未带 --apply 不安装。该版本仍使用原有追加逻辑，不会自动整理历史重复块或清理旧版本。

## 自定义数据目录

默认使用当前用户的 `.dsh` 数据目录和 `desktop` profile。目标必须与实际运行的 DSH 一致。

退出 DSH 后，在解压目录终端中运行下例，替换占位符；使用其他 profile 时也需替换 `desktop`：

```powershell
node tools/manage.mjs install --apply --dsh-home "<DSH数据目录>" --profile desktop
node tools/manage.mjs rollback --apply --dsh-home "<DSH数据目录>" --profile desktop
```

也可以先设置 `DSH_HOME` 环境变量，再运行安装或回退脚本。安装器不会自动启动 DSH。

## 画质与可选搭配

动态及极清画质可能增加资源使用。需要更低负担时可手动选择标准画质、静态或专注模式；已有偏好保持。额度挂件及其角色图库属于独立插件，本皮肤不读取其账户、复制其配置或自动导入角色图。

安装包的 [extras/quota-widget](../extras/quota-widget/README.md) 附小祀透明头像及导入说明。专注、系统减少动态效果或页面不可见时，不会为新场景主动加载动态视频；恢复可播放状态后再加载，已有播放阶段按场景行为保留。
