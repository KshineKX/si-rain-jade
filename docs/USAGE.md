# 使用说明

## 场景与动态

| 场景 | 动态 |
|---|---|
| 雨声里的片刻 | 循环动态 |
| 窗榻听雨 | 循环动态 |
| 铺卷小憩 | 循环动态 |
| 墨境桥行 | 静态 |
| 掌柜闲时 | 静态 |
| 祀的鬼画符 | 静态 |
| 雪庭温泉 | 开场动作后进入微动态循环 |

温泉开场约 5 秒，之后保持翘腿姿态，循环播放水波、白气与慢雪。专注模式暂停在当前阶段，恢复默认或观赏后继续播放。切换画质保留播放阶段；要重播开场，在设置中先选静态，再选动态。

标准视频为 1278×720，极清为 3834×2160；极清由本地增强得到。温泉只有雪日场景，深浅外观共用这组素材。

## 阅读与观赏

设置 → 阅读可调节雾层浓度。默认和专注分别保存设置，重启后保留。观赏隐藏阅读衬底与页面内容，工具栏静止后淡出；鼠标移动或 Tab 可唤回。键盘焦点停留在工具栏时保持可见。

观赏期间页面通知和弹层也会隐藏，需处理交互时请先退出观赏。

## 固定会话入口

左栏显示名为 **祀 · 画境**，它打开你已有的会话：

1. 优先匹配唯一且未归档的 **祀 · 管理员的画境会话**。
2. 没有匹配时，查找唯一的 **祀 · 画境** 工作区；其中只有一个未归档、非空的可用会话时，打开该会话。
3. 重名、有歧义或没有有效目标时，入口停用。

可将自己的目标会话重命名为上述完整标题。入口不会自动创建会话、移动记录或发送消息。

## 自定义数据目录

默认使用当前用户的 `.dsh` 数据目录和 `desktop` profile。目标必须与实际运行的 DSH 一致。

退出 DSH 后，在解压目录终端中运行下例，替换占位符；使用其他 profile 时也需替换 `desktop`：

```powershell
node tools/manage.mjs install --apply --dsh-home "<DSH数据目录>" --profile desktop
node tools/manage.mjs rollback --apply --dsh-home "<DSH数据目录>" --profile desktop
```

也可以先设置 `DSH_HOME` 环境变量，再运行安装或回退脚本。安装器不会自动启动 DSH。
