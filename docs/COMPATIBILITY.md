# 兼容性

## 0.1.1

| 环境 | 状态 |
|---|---|
| Windows / DSH 0.2.2-rc.1 | 当前推荐组合，已检查界面显示、模式切换、动态播放及安装升级路径 |
| DSH 0.2.1-rc.5 | 本版兼容性尚未确认；已有可用安装建议先保留，可从历史发行版选择原版本 |
| DSH 0.2.1-rc.4 | 本版兼容性尚未确认 |
| macOS / Linux / 其他版本 | 暂未确认支持 |

需要 Node.js 22.19+ 或 24+，并确保 `node` 在 PATH 中。安装包不包含 Node.js；不会自动寻找 DSH 内置运行时。

皮肤不更新 DSH 宿主。升级宿主前应保留原应用与数据备份；皮肤的 `Rollback.cmd` 只恢复皮肤，不能恢复宿主的数据迁移。

宿主更新可能改变界面结构与接口。上述兼容范围只针对本皮肤，不代表其他插件的兼容性。
