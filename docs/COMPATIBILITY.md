# 兼容性

## 0.2.0

| 环境 | 验证范围 |
|---|---|
| Windows / DSH 0.2.2-rc.1 | 开发方已在独立官方宿主验证开屏两条真实媒体路径，以及窗口比例、署名布局、场景与主题收尾；用户已验收当前实现。不能扩大为所有历史页面和其他插件全量兼容 |
| DSH 0.2.1-rc.5 | 早期历史版本有验证记录，本版未重测 |
| DSH 0.2.1-rc.4 | 本版未实测 |
| macOS / Linux / 其他宿主 | 未验证 |

Node.js 22.19+ 或 24+，`node` 需在 PATH 中；包内不含 Node，也不自动调用 DSH 内置运行时。自定义数据目录请按[使用说明](USAGE.md#自定义数据目录)指定。

通过 DSH bundle、模块加载器、ctx.effect 和 webServer 加载；不修改宿主安装文件，不需要外部 CDP 驻留。外观仍依赖 DOM 标记、CSS 语义后缀与主题属性；data-slot 是定位锚点，不等于所有外观均通过稳定主题扩展 API 完成。宿主结构变化可能影响显示。

皮肤回退不能代替宿主降级及数据恢复。旧版[0.1.1](https://github.com/KshineKX/si-rain-jade/releases/tag/v0.1.1)及更早版本仍保留。本轮发布侧核验冻结输入、构建、清单、离线测试和下载字节，不重复操作个人窗口或发送模型消息。
