# 兼容性

## DSH 0.2.2-rc.3 适配

本版为 Beta，支持 Windows / DSH 0.2.2-rc.3。已在作者个人环境安装使用，现有界面与操作予以保留。

| 环境 | 验证范围 |
|---|---|
| Windows / DSH 0.2.2-rc.3 | 使用官方同版本 npm Web 宿主隔离检查原生侧栏HOC、正文实际拖动、CSS zoom、视图/草稿、全局面板返回及开屏；作者已在升级后的桌面环境使用并选择保留当前行为；Electron 各级缩放、Windows 菜单和其他插件组合没有穷尽测试 |
| DSH 0.2.2-rc.1 / rc.2 | 不继承旧皮肤的兼容结论；缺少本版必要扩展位时，安装前检查会停止 |
| DSH 0.2.1-rc.5 | 历史版本有验证记录；本版未重测，不能继承旧版兼容结论 |
| DSH 0.2.1-rc.4 | 本版未实测 |
| macOS / Linux / 其他宿主 | 未验证 |

Node.js 22.19+ 或 24+，`node` 需在 PATH 中；包内不含 Node，也不自动调用 DSH 内置运行时。自定义数据目录请按[使用说明](USAGE.md#自定义数据目录)指定。

通过 DSH bundle、模块加载器和只读 webServer 媒体路由加载；不修改宿主安装文件，不需要外部 CDP 驻留。快捷工具由官方 `shell.overlay` Slot 注册的 Portal 承载，固定会话按钮由 `sidebar.session.action` HOC 承载并保留原生新会话；配色通过 `theme.overrideTokens` 提供可撤销主题层。

玻璃材质与阅读衬底仍保留受控DOM/CSS适配。布局标记集中在共享兼容契约中，以语义标记为主，少量装饰保留CSS后缀兼容。它不是完全无DOM适配的主题；宿主结构变化仍可能影响外观。核心布局无法识别时停止皮肤效果，保留原生界面，结构恢复后可重新挂载。

升级检查与维护命令见 [维护说明](MAINTENANCE.md)。静态契约满足不代表运行验收；隔离运行采用生成的虚构资料，流式验证也不代表真实模型回复的全面采样。

本轮验证是隔离宿主的有界运行与界面检查，不是物理双屏测试、24 小时长跑或所有用户环境的稳定性保证。可用标准画质、静态或专注模式降低动态资源需求。

皮肤回退不能代替宿主降级及数据恢复。旧版[0.2.0](https://github.com/KshineKX/si-rain-jade/releases/tag/v0.2.0)及更早版本仍保留。个人使用反馈和隔离检查分别记录，不将其扩大为所有页面、显示设置或设备的人工验收通过。
