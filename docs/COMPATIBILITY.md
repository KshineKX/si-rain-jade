# 兼容性

## 0.3.0-beta.1 维护预览

本版为 Beta，新架构尚未在用户个人 DSH 安装；不能作为长期稳定版或跨平台兼容承诺。

| 环境 | 验证范围 |
|---|---|
| Windows / DSH 0.2.2-rc.1 | 本轮在独立官方宿主验证 Slot/Theme 接入、宽正文跟随、三档显示、动态暂停、不兼容降级和注销还原；包含 1×/2× 逻辑缩放。已有媒体和开屏沿用文件，不能扩大为所有历史页面或其他插件全量兼容 |
| DSH 0.2.1-rc.5 | 历史版本有验证记录；本版未重测，不能继承旧版兼容结论 |
| DSH 0.2.1-rc.4 | 本版未实测 |
| macOS / Linux / 其他宿主 | 未验证 |

Node.js 22.19+ 或 24+，`node` 需在 PATH 中；包内不含 Node，也不自动调用 DSH 内置运行时。自定义数据目录请按[使用说明](USAGE.md#自定义数据目录)指定。

通过 DSH bundle、模块加载器和只读 webServer 媒体路由加载；不修改宿主安装文件，不需要外部 CDP 驻留。快捷工具由官方 `shell.overlay` Slot 注册的 Portal 承载，配色通过 `theme.overrideTokens` 提供可撤销的主题层，深浅切换交由 Theme 服务处理。

玻璃材质、阅读衬底和固定会话按钮仍保留受控的 DOM/CSS 适配。布局定位集中在 host adapter 中，以语义标记为主，消息气泡保留一处 CSS 后缀兼容。它不是完全无 DOM 适配的主题；宿主结构变化仍可能影响外观。核心布局无法识别时停止皮肤效果，保留原生界面；结构恢复后可重新挂载。

开发方记录包括 25 项离线测试、14 项布局检查、6 项接口与注销还原检查，以及约 10 分钟的非插桩观察。流式验证采用模拟更新，不代表真实模型回复的全面采样；页面 JS 堆数据不是整个 DSH 内存或显存。

本轮验证是隔离宿主的有界运行与界面检查，不是物理双屏测试、24 小时长跑或所有用户环境的稳定性保证。可用标准画质、静态或专注模式降低动态资源需求。

皮肤回退不能代替宿主降级及数据恢复。旧版[0.2.0](https://github.com/KshineKX/si-rain-jade/releases/tag/v0.2.0)及更早版本仍保留。个人安装与界面验收单独进行，不将隔离检查说成已经替用户升级或验收。
