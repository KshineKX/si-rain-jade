# 小祀额度挂件头像

`si-avatar.png` 是透明背景的角色头像，可搭配独立插件 [DeepSeek Balance Whale Widget](https://github.com/MeteorNOX/DeepSeek-Balance-Whale-Widget) 使用。本目录只附图片，不包含额度插件，也不自动导入角色或改动账户配置。

1. 在 DSH 中安装并启用上述额度挂件插件。
2. 打开挂件的“角色图库”，选择导入图片，选取本目录的 `si-avatar.png`。
3. 给角色命名并选用该头像；显示大小和位置按挂件插件的设置调整。

这里导入的是角色图，不是泡泡图。挂件插件不同版本的菜单名称可能稍有不同。
